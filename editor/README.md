# JACK12 フライヤーエディタ

ブラウザで動く WYSIWYG エディタ。1つのデータから **A4チラシ** と **縦長スクロール** を、**上品 / 熱量** の2トーンで作成・微調整・書き出しできます。

## かんたん起動（ダブルクリック）

プロジェクト直下の **`.command`** をダブルクリックするだけ（ターミナル操作不要）：

- **`エディタ起動.command`** … セットアップ→サーバ起動→ブラウザで編集画面を開く（Chrome優先）。閉じると停止。
- **`PDF書き出し.command`** … 4種（A4×2・縦長×2）の PDF / PNG を `output/editor/` に書き出して、フォルダを開く。

※ 初回だけ自動で `npm install` と書き出し用ブラウザの取得が走るため少し時間がかかります。
※ Node.js（npm）が必要です。未導入なら https://nodejs.org からインストール。

## 手動で起動（コマンド派向け）

```bash
cd editor
npm install        # 初回のみ
npm run dev        # → http://localhost:5173 をブラウザで開く
```

### 画面の操作
- **トーン**（上品 / 熱量）と**出力**（縦長 / A4）をツールバーで切替。**ズーム**で拡大縮小。
- **文字**：プレビュー上の文字を直接クリックして入力（青枠が出ます）。改行も自由。日本語は**文節単位で自動改行**（はみ出し・変な改行を抑制）。
- **写真**：写真にマウスを乗せて「写真を変更」→ 右パネルのギャラリーから選択。写真を**ドラッグすると表示位置（トリミング）**を調整＝顔が切れないように。右パネルのスライダー（左右・上下）でも微調整可。
- **配色・テーマ**：右パネルでトーンごとの色・カードの色・写真の暗さを調整。
- **保存 / 読込 / リセット**：編集内容は自動でブラウザに保存。「保存(JSON)」で `jack12-doc.json` を書き出し、別PCや書き出しに使えます。

## 書き出し（PDF / PNG）

開発サーバを起動したまま、別ターミナルで:

```bash
cd editor
npm run export
```

`../output/editor/` に4種（A4×2トーン・縦長×2トーン）を、各 **PDF・PNG・JPG** の3形式で出力します。
- A4 … 210×297mm の PDF ＋ 高解像度 PNG/JPG
- 縦長 … 幅1080px の PNG/JPG ＋ PDF

### 編集内容を書き出しに反映するには
1. エディタで編集 → 「保存(JSON)」で `jack12-doc.json` をダウンロード
2. それを `editor/doc.json` という名前で置く
3. `npm run export`

（`doc.json` が無い場合は初期内容＝現行デザインで書き出します）

## 構成
- `src/data/doc.ts` … 文言・写真・テーマの初期データ（現行チラシを移植）
- `src/components/Scroll.tsx` / `Flyer.tsx` … 縦長 / A4 のレイアウト
- `src/editing.tsx` … 文字編集・写真の焦点ドラッグ
- `src/styles.css` … デザインCSS（`word-break: auto-phrase` で文節改行）
- `scripts/export.mjs` … Playwright(Chromium) で PDF/PNG 書き出し

## メモ
- フォントは Mac 内蔵のヒラギノ（角ゴシック / 明朝）を参照。別環境では `styles.css` の `--font-g/--font-s` を変更。
- ブラウザPDFは RGB。厳密な CMYK 入稿が要る場合は別途変換（Ghostscript等）を追加予定。
