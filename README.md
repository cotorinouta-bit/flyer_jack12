# JACK12 企業向け資料 引き継ぎパッケージ

このフォルダは、JACK12の企業向け資料作成を別環境へ引き継ぐための一式です。

## まず見るファイル

- `work/jack12_official_profile_and_programs.md`
  - 公式プロフィール、主要実績、事業領域、プログラム料金を整理したMarkdown原稿です。
- `output/pdf/jack12_peace_program_flyer.pdf`
  - A4想定の1枚チラシPDFです。
- `output/pdf/jack12_mobile_scroll_profile.pdf`
  - 縦長スクロール型プロフィールPDFです。

## 同梱データ

- `work/`
  - Markdown原稿
  - PDF/PNG生成用スクリプト
- `output/pdf/`
  - 生成済みPDF
  - 生成済みPNG
- `assets/`
  - チラシ生成に使った画像素材一式

## 別環境で再生成する場合

`work/make_jack12_flyer.py` は、スクリプト自身の位置から素材・出力先を自動で解決します（`work/` の親をプロジェクト直下とみなす）。フォルダ構成（`work/` `assets/` `output/`）を保ったままであれば、パスの書き換えは不要です。

```bash
# このフォルダ直下で実行
python3 work/make_jack12_flyer.py
```

### 前提

- Python 3 と Pillow（`pip install Pillow`）
- macOS のヒラギノフォント（角ゴシック W4/W6/W8・明朝 ProN）。別OSで動かす場合は、スクリプト冒頭の `FONT_*` を環境にあるフォントへ変更してください。

生成物は `output/pdf/` に上書き出力されます（PDF・PNG 各2種）。
